# 2Fast Pixel Icon Pack

A packaged pixel-art identity set for 2Fast, a tray-first desktop utility for retrieving OTP-style codes from recent Gmail and Outlook messages.

## Contents

- Canonically named source PNGs under `assets/`
- Windows multi-resolution application icon: `assets/app/app-icon-main.ico`
- Pixel-preserving resized PNGs under `exports/`
- Agent-ready integration instructions: `AGENT_INTEGRATION_PROMPT.md`
- Visual reference material under `reference/`

## Visual language

- Dark navy backgrounds
- Warm off-white envelope forms
- Electric-blue lightning and motion accents
- Lime-green OTP tickets and success states
- Chunky, crisp pixel-art geometry

Use `image-rendering: pixelated` when scaling these assets in a browser or Electron renderer.
